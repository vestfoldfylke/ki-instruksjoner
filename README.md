# ki-instruksjoner
Dette repoet inneholder KI-instruksjoner som kan benyttes når man ønsker å opprette KI-assistenter. Vestfold fylkeskommune benytter noen av disse instruksjonene for KI-assistenter publisert via vår egen KI-tjeneste "Munin".

Dette er første branch i repoet og brukes til å enes om den strategiske retningen til arbeidet med utvikling og deling av KI-instruksjkoner i fylkeskommunen.
Branchen er et førsteutkast og inneholder ingen offisielt kvalitetssikrede instruksjoner.
